# 实验室成员管理系统 - 数据库设计

> 文档版本：V1.0

## 1. 数据库

- 名称：`lab_system`
- MySQL：8.x
- 字符集：`utf8mb4`

## 2. 数据表

V1.0 只需要：

`lab_member`

## 3. 表结构

| 字段 | 类型 | NULL | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT | NO | AUTO_INCREMENT | 主键 |
| name | VARCHAR(50) | NO | - | 姓名 |
| student_no | VARCHAR(30) | NO | - | 学号 |
| gender | TINYINT | NO | - | 性别 |
| grade | VARCHAR(20) | NO | - | 年级 |
| major | VARCHAR(100) | NO | - | 专业 |
| phone | VARCHAR(20) | YES | NULL | 手机号 |
| email | VARCHAR(100) | YES | NULL | 邮箱 |
| status | TINYINT | NO | 1 | 状态 |
| create_time | DATETIME | NO | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | NO | CURRENT_TIMESTAMP | 更新时间 |

## 4. 字段规则

### id

主键、自增、非空。

### name

姓名，非空，最大 50 字符。

### student_no

学号，非空，唯一，最大 30 字符。

### gender

- 0：未知
- 1：男
- 2：女

### grade

年级，例如 `2023`。

### major

专业，例如软件工程、人工智能。

### phone

可为空；填写时需要业务层格式校验。

### email

可为空；填写时需要业务层格式校验。

### status

- 0：已离开实验室
- 1：正常

默认值为 1。

### create_time

创建时间，系统自动生成。

### update_time

最后修改时间，系统自动更新。

## 5. 数据库约束

必须：

```text
id         PRIMARY KEY
student_no UNIQUE
name       NOT NULL
student_no NOT NULL
gender     NOT NULL
grade      NOT NULL
major      NOT NULL
status     NOT NULL
```

## 6. 索引

必须存在：

- 主键索引：`id`
- 唯一索引：`student_no`

如为列表查询增加其他索引，需要说明理由。

## 7. 初始化数据

必须提供：

`sql/init.sql`

至少 10 条数据，且覆盖：

- 不同年级
- 不同性别
- 不同专业
- 正常成员
- 已离开成员
- 有联系方式和无联系方式的数据

## 8. 数据完整性

数据库必须保证：

- 学号唯一
- 必填字段不能为 NULL
- ID 自动生成
- 时间字段正确

## 9. 设计原则

字段语义清晰、类型合理、约束合理、时间信息完整、避免明显冗余数据。
