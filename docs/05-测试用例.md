# 实验室成员管理系统 - 测试用例

> 文档版本：V1.0

## 1. 测试方式

可使用：

- Swagger
- Apifox
- Postman
- JUnit
- MockMvc

建议：Swagger/Apifox 做接口功能测试，JUnit/MockMvc 做自动化测试。

## 2. 新增测试

| 编号 | 场景 | 预期 |
|---|---|---|
| ADD-001 | 正常新增 | 200 |
| ADD-002 | name 为空 | 400 |
| ADD-003 | studentNo 为空 | 400 |
| ADD-004 | studentNo 重复 | 400 |
| ADD-005 | gender=5 | 400 |
| ADD-006 | grade 为空 | 400 |
| ADD-007 | major 为空 | 400 |
| ADD-008 | status=5 | 400 |
| ADD-009 | 手机号非法 | 400 |
| ADD-010 | 邮箱非法 | 400 |

## 3. 详情查询

| 编号 | 场景 | 预期 |
|---|---|---|
| GET-001 | 查询存在成员 | 200 |
| GET-002 | 查询不存在成员 | 404 |

## 4. 列表查询

| 编号 | 场景 | 预期 |
|---|---|---|
| LIST-001 | 默认查询 | 200，page=1，pageSize=10 |
| LIST-002 | page=2&pageSize=5 | 返回第二页 |
| LIST-003 | name=张 | 姓名均包含“张” |
| LIST-004 | studentNo=20230001 | 返回对应成员 |
| LIST-005 | grade=2023 | 返回成员均为 2023 |
| LIST-006 | status=1 | 返回成员均为正常 |
| LIST-007 | 多条件组合 | 所有条件同时满足 |

## 5. 修改测试

| 编号 | 场景 | 预期 |
|---|---|---|
| UPDATE-001 | 正常修改 | 200 |
| UPDATE-002 | 修改不存在成员 | 404 |
| UPDATE-003 | 修改为重复学号 | 400 |
| UPDATE-004 | gender=5 | 400 |
| UPDATE-005 | status=5 | 400 |
| UPDATE-006 | updateTime 更新 | 新时间晚于旧时间 |

## 6. 删除测试

| 编号 | 场景 | 预期 |
|---|---|---|
| DELETE-001 | 正常删除 | 200 |
| DELETE-002 | 删除不存在成员 | 404 |
| DELETE-003 | 删除后查询 | 404 |
| DELETE-004 | 删除后列表查询 | 不再出现 |

## 7. 边界测试

| 编号 | 场景 | 要求 |
|---|---|---|
| EDGE-001 | 超长 name | 400 或合理处理 |
| EDGE-002 | 超长 studentNo | 不允许产生未处理 500 |
| EDGE-003 | page=0 | 合理校验 |
| EDGE-004 | pageSize=0 | 合理校验 |
| EDGE-005 | page=-1 | 合理校验 |
| EDGE-006 | pageSize=-1 | 合理校验 |

## 8. 数据一致性

### DATA-001

新增 → 查询，查询结果与新增数据一致。

### DATA-002

修改 → 查询，查询结果为修改后的数据。

### DATA-003

删除 → 查询，必须返回 404。

## 9. 自动化测试要求

执行：

```bash
mvn test
```

至少覆盖：

### Service

- 正常新增
- 重复学号
- 查询不存在
- 修改不存在
- 删除不存在

### Controller

- 新增成功
- 参数错误
- 查询成功
- 查询不存在
- 修改成功
- 删除成功
