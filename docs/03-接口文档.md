# 实验室成员管理系统 - API 接口文档

> 文档版本：V1.0  
> Base URL：`/api`

## 1. 接口列表

| Method | URL | 功能 |
| --- | --- | --- |
| POST | `/api/members` | 新增成员 |
| GET | `/api/members/{id}` | 查询成员详情 |
| GET | `/api/members` | 分页/条件查询 |
| PUT | `/api/members/{id}` | 修改成员 |
| DELETE | `/api/members/{id}` | 删除成员 |

## 2. 新增成员

```http
POST /api/members
Content-Type: application/json
```

请求：

```json
{
  "name": "张三",
  "studentNo": "20230001",
  "gender": 1,
  "grade": "2023",
  "major": "软件工程",
  "phone": "13800138000",
  "email": "zhangsan@example.com",
  "status": 1
}
```

参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | ---: | --- |
| name | String | 是 | 姓名 |
| studentNo | String | 是 | 学号 |
| gender | Integer | 是 | 0/1/2 |
| grade | String | 是 | 年级 |
| major | String | 是 | 专业 |
| phone | String | 否 | 手机号 |
| email | String | 否 | 邮箱 |
| status | Integer | 是 | 0/1 |

成功：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1
  }
}
```

参数错误或学号重复：`400`。

## 3. 查询详情

```http
GET /api/members/{id}
```

成功返回成员完整信息；不存在返回：

```json
{
  "code": 404,
  "message": "成员不存在",
  "data": null
}
```

## 4. 查询列表

```http
GET /api/members
```

Query 参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | ---: | ---: | --- |
| page | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页数量 |
| name | String | 否 | - | 姓名模糊查询 |
| studentNo | String | 否 | - | 学号 |
| grade | String | 否 | - | 年级 |
| status | Integer | 否 | - | 状态 |

示例：

```text
GET /api/members?page=1&pageSize=10
GET /api/members?page=1&pageSize=10&name=张
GET /api/members?page=1&pageSize=10&grade=2023&status=1
```

返回：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [],
    "total": 0,
    "page": 1,
    "pageSize": 10
  }
}
```

必须使用数据库分页，禁止查询全部数据后再在 Java 内存分页。

## 5. 修改成员

```http
PUT /api/members/{id}
Content-Type: application/json
```

请求结构与新增基本一致。

要求：

- ID 不存在：404
- 参数错误：400
- studentNo 重复：400
- 修改成功：200
- updateTime 更新

## 6. 删除成员

```http
DELETE /api/members/{id}
```

成功：

```json
{
  "code": 200,
  "message": "删除成功",
  "data": null
}
```

不存在：404。

## 7. 参数校验

必须校验：

- name 非空
- studentNo 非空且唯一
- gender ∈ {0,1,2}
- grade 非空
- major 非空
- status ∈ {0,1}
- phone（填写时）格式正确
- email（填写时）格式正确

## 8. Swagger/OpenAPI

项目必须提供 Swagger/OpenAPI 文档，并能够：

- 查看接口
- 查看参数
- 查看 Request Body
- 查看 Response
- 直接调用接口

推荐访问：

```text
/swagger-ui/index.html
```

## 9. RESTful 要求

使用：

```text
POST   /api/members
GET    /api/members
GET    /api/members/{id}
PUT    /api/members/{id}
DELETE /api/members/{id}
```

不要设计为 `/addMember`、`/deleteMember` 等 RPC 风格路径。
